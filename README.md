# adr-agent-template

An Obsidian vault template for making architecture decisions with an AI agent.

The agent reads your git repositories, lays out the options and their trade-offs, and asks you questions one round at a time. You decide, and the agent records the result as an ADR.

## Status

This release has only the repository files. The vault template comes in a later release.

## Usage

Download the vault archive from [Releases](https://github.com/RottenSea/adr-agent-template/releases) and unzip it into a directory of its own, outside any clone of this repository. Open that directory as a vault in Obsidian, then start your agent from the vault root.
